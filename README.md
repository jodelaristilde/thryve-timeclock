# Thryve.Today Training Center – Employee Time Clock

- **Admin page:** `index.html` – register employees and view or download weekly hours (PDF or CSV).
- **Employee clock-in form:** https://form.jotform.com/262835728338064
- **QR code for the facility sign:** `clock-in-qr.png` (opens the clock-in form)

The admin page asks for a Jotform API key the first time it opens. The key is saved only
in that browser; it is never stored in these files.
